# Java-Terminal-Taschenrechner

Ein einfacher Konsolen-Taschenrechner in Java, der mit `Scanner` und `String.split` arbeitet, um Rechenausdrücke im Terminal auszuwerten.

## Funktionen

- Grundrechenarten (`+`, `-`, `*`, `/`)
- Endlosschleife für mehrere Berechnungen hintereinander
- Beenden des Programms über `q` bzw. `Q`
- Grundlegende Prüfung von Operatoren und Eingaben

## Starten

1. Stelle sicher, dass ein JDK installiert ist.
2. Kompiliere die Datei: `javac Taschenrechner.java`
3. Starte das Programm: `java Taschenrechner`

## 🇬🇧 English Version

# Java Console Calculator

A command-line calculator in Java using `Scanner` and `String.split` to parse and evaluate two-operand arithmetic expressions in the terminal.

## Features

- Basic arithmetic operations (`+`, `-`, `*`, `/`)
- Continuous loop for multiple calculations in one session
- Quit command (`q` / `Q`) to exit cleanly
- Basic input and operator validation

## How to Run

1. Make sure a JDK is installed.
2. Compile the source file: `javac Taschenrechner.java`
3. Run the program: `java Taschenrechner`
